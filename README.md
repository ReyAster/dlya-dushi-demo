# Для души: лендинг студии флористики (демо)

Учебный проект: одностраничный лендинг студии флористики с каруселью букетов,
пошаговой анкетой и цветком, который раскрывается по мере ответов.

В этой демо-версии анкета работает, но данные никуда не отправляются.
Тексты оферты и политики персональных данных тестовые.

Стек: HTML, CSS, JavaScript без фреймворков и сборки.
